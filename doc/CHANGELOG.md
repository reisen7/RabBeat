# 更新日志

本文件记录 RabBeat 各版本的功能变更。发版流水线会自动抽取对应版本的段落作为 GitHub Release 的更新说明，标题格式须为 `## [x.y.z]`。

## [0.0.2] - 2026-11-13

### 新增

- QQ 音乐加密格式解密：支持 `.mgg`/`.mflac`/`.qmcogg` 等 QMC 后缀，扫描时自动解密入库，与 `.ncm` 同一套流程
- OGG/Opus 内嵌封面解析：读取 Vorbis comment 里的 `METADATA_BLOCK_PICTURE`/`COVERART`，补上了 MediaStore 不生成专辑图的情况
- 在线歌词匹配：本地歌曲按标题+歌手+时长匹配网易云歌词（含双语合并），自动存入本地
- 本地歌词导入：播放页可选择 `.lrc`/`.txt` 文件作为当前歌曲歌词
- 歌词偏移调节：播放页可调歌词快慢（±0.1s/0.5s/1s 步进），每首歌独立保存
- 移动网络在线缓存开关：设置 → 离线下载，关闭后在线歌曲在蜂窝网络下不拉流不缓存
- 检查更新：设置页可直接检查 GitHub 新版本，支持镜像降级，带加载弹窗

### 变更

- 播放页背景跟随封面主色变化（修复取色只识别内置资源的问题）
- 移除「关联其他歌歌词」功能
- 移除「音质偏好」占位行、「仅 Wi-Fi 下载」、「自动离线常用歌单」占位开关
- 网易云歌单导入弹窗补充分享链接获取说明
- 修复首页滑动卡顿：背景实时模糊改静态位图，预热封面解码

## [0.0.1] - 2026-11-11

首个公开版本。

### 新增

- Apple Music 风格界面：首页、曲库、搜索、播放页、个人页，五色强调色 + 自定义背景图 + 模糊/暗度/卡片透明度调节
- 本地音乐扫描：MediaStore + 文件夹导入，支持去重、时长/大小过滤
- `.ncm` 网易云加密文件解密播放
- 播放列表：新建、编辑、批量删除、长按拖拽排序、自定义封面、最新歌曲封面自动作为歌单封面
- 「我喜欢」默认歌单与收藏
- 网易云歌单导入（分享链接），在线播放与缓存
- 隐藏歌曲/文件夹（假删除），设置中可恢复
- 歌词：同名 `.lrc`、内嵌歌词、双语合并显示
- 库备份与恢复
- 应用日志：滚动保留 7 天，设置中可导出
- GitHub Actions 签名打包，tag 发版自动发布 Release
