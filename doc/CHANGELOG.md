# 更新日志

本文件记录 RabBeat 各版本的功能变更。发版流水线会自动抽取对应版本的段落作为 GitHub Release 的更新说明，标题格式须为 `## [x.y.z]`。

## [0.0.5] - 2026-11-17

### 新增

- Windows 桌面版：首页、本地音乐、最近添加、最常播放、我喜欢、已隐藏、自建歌单，以及唱片和歌词播放页
- 桌面端导入本地文件夹和网易云歌单；`.ncm`、`.qmc` 扫描时解密入库
- 桌面端外观和窗口：主题与强调色、背景图、模糊、压暗、卡片透明度；关闭可收进系统托盘；缓存目录和转换目录可改
- 同一 Wi-Fi 同步：电脑设置里打开「和手机同步歌单」并出示二维码，手机在设置里选「和电脑同步」后扫码。歌单、喜欢，以及缺的歌曲、封面和歌词会对齐

### 变更

- 歌单未自定义封面时，封面改为列表中第一首有封面的歌曲
- 自己设置的本地歌单封面在同步后保留
- 桌面端把歌曲加入歌单时插到列表最前，并用自动消失的提示说明添加结果
- 手机搜索框里的文本光标改为垂直居中

### 修复

- Android 发版的编译 SDK 升到 37，流水线可以打出手机安装包

## [0.0.4] - 2026-11-15

### 变更

- 检查更新弹窗改版：弹窗内直接展示该版本的更新说明（可滚动），「立即下载」改为 APK 直链直接开始下载，不再跳易卡死的 Release 页面；保留「查看页面」入口

## [0.0.3] - 2026-11-15

### 新增

- 曲库 tab 跟手翻页：歌曲/专辑/艺人/文件夹之间按住左右拖动直接翻页，与系统翻页手感一致
- 迷你播放条滑动切歌：左滑下一曲、右滑上一曲，跟手拖动 + 甩出过渡动画，轻扫即切
- 「最近添加」页面：首页区块进入按添加时间排序的完整列表，分页加载，支持播放/收藏/加歌单/隐藏等操作

### 变更

- 播放页切歌动画重做：封面先行滑出，新封面与歌名同步滑入，随后背景色渐变、音频切换
- 封面加载优化：相邻曲目封面提前进缓存 + 图片淡入，切歌不再闪默认占位图；模糊背景交叉淡变
- 播放页控制区重新设计：白色圆形播放键 + 药丸形切歌键，长歌名自动跑马灯
- 隐藏改为按文件生效：隐藏状态绑定文件路径，同名不同路径的文件互不影响；同一文件重扫仍保持隐藏
- 去重合并调整：跨来源合并只认同目录，隐藏条目不再吞掉新导入的同名文件

### 修复

- 队列最后一首点「下一曲」无反应（现在回绕到队列头）
- 冷启动恢复后「下一曲」不可点
- 进播放页/点播放时误播切歌动画（现在只在真换歌时触发）
- 首页「最近添加」入口跳错页面

## [0.0.2] - 2026-11-13

### 新增

- QQ 音乐加密格式解密：支持 `.mgg`/`.mflac`/`.qmcogg` 等 QMC 后缀，扫描时自动解密入库，与 `.ncm` 同一套流程
- OGG/Opus 内嵌封面解析：读取 Vorbis comment 里的 `METADATA_BLOCK_PICTURE`/`COVERART`，补上了 MediaStore 不生成专辑图的情况
- 在线歌词匹配：本地歌曲按标题+歌手+时长匹配网易云歌词（含双语合并），自动存入本地
- 本地歌词导入：播放页可选择 `.lrc`/`.txt` 文件作为当前歌曲歌词
- 歌词偏移调节：播放页可调歌词快慢（±0.1s/0.5s/1s 步进），每首歌独立保存
- 移动网络在线缓存开关：设置 → 离线下载，关闭后在线歌曲在蜂窝网络下不拉流不缓存
- 检查更新：设置页可直接检查 GitHub 新版本，支持镜像降级，带加载弹窗

### 变更

- 播放页背景跟随封面主色变化（修复取色只识别内置资源的问题）
- 移除「关联其他歌歌词」功能
- 移除「音质偏好」占位行、「仅 Wi-Fi 下载」、「自动离线常用歌单」占位开关
- 网易云歌单导入弹窗补充分享链接获取说明
- 修复首页滑动卡顿：背景实时模糊改静态位图，预热封面解码

## [0.0.1] - 2026-11-11

首个公开版本。

### 新增

- Apple Music 风格界面：首页、曲库、搜索、播放页、个人页，五色强调色 + 自定义背景图 + 模糊/暗度/卡片透明度调节
- 本地音乐扫描：MediaStore + 文件夹导入，支持去重、时长/大小过滤
- `.ncm` 网易云加密文件解密播放
- 播放列表：新建、编辑、批量删除、长按拖拽排序、自定义封面、最新歌曲封面自动作为歌单封面
- 「我喜欢」默认歌单与收藏
- 网易云歌单导入（分享链接），在线播放与缓存
- 隐藏歌曲/文件夹（假删除），设置中可恢复
- 歌词：同名 `.lrc`、内嵌歌词、双语合并显示
- 库备份与恢复
- 应用日志：滚动保留 7 天，设置中可导出
- GitHub Actions 签名打包，tag 发版自动发布 Release
